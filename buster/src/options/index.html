VODKA · OPTIONAL ONE-SHOT ASSISTANCE

Buster 人机辅助

内嵌 Buster 的 reCAPTCHA 辅助。默认手动；开启自动后可先勾选“进行人机身份验证”，再按现有流程尝试一次音频辅助。不会连续尝试，不处理 Cloudflare / hCaptcha。

本地识别

建议先准备 Whisper Tiny 模型，再返回验证码点击 Buster。首次会从 Hugging Face 下载模型并缓存在浏览器，可能需要较长时间与磁盘空间。音频由本地模型处理，不发送至云端识别服务。

自动人机辅助（默认关闭）

勾选入口无需下载模型；音频辅助只使用已经准备的本地模型；当前验证码框的本次页面生命周期最多一次识别/填入/提交。无音频、模型缺失或失败即交回手动，不重试、不自动下载模型、不自动续跑探测/抽卡。云服务仍需手动点击。

勾选后点击下面的「保存设置」。服务工作线程重启不会重复本框的尝试；勾选入口和音频辅助各自每次浏览器会话最多 64 个框。

语音识别服务

默认使用本地识别。也可自行配置云服务；选择云服务后，验证码音频会发送给该服务，可能产生费用。集成版不包含 Buster 官方托管密钥，也不包含原生模拟输入客户端。
