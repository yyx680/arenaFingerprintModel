三步开始，无需控制台。

此插件不会自动创建任务，也不替你切换网站模式。

  1. 打开自己的 DesignArena 页面

    自行选择网站提供的单 Agent 会话模式。

  2. 点击「开始新一轮观察」

    仅在当前标签页安装探针，再正常发送自己的任务。

  3. 查看声明或导出报告

    关闭弹窗不影响页面内的观察。刷新页面后需重新开始。

仅使用 activeTab 和 scripting 权限。无常驻后台、无全站访问权限，不读取 Cookie 或浏览器存储。只解析页面正常收到的数据；不绕过认证、付费、投票揭示或防护。

不支持独立 EventSource、WebSocket、Web Worker 或服务端内部调用。多个声明标记歧义；内部 ID 不当作型号。尚未进行浏览器现场测试。
