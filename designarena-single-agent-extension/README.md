# Scope · DesignArena 单 Agent 观察与自动抽卡（v1.1.0）

这是可直接加载的 Manifest V3 扩展目录，面向支持相关扩展 API 的 Chrome / Edge。不需要 Node.js，不依赖项目中的其他脚本，不要求每次打开开发者控制台。

## 安装

1. 在浏览器菜单中打开「扩展程序 / 管理扩展程序」。
2. 开启该页面的「开发者模式」。
3. 选择「加载已解压的扩展程序」。
4. 选择 **designarena-single-agent-extension** 目录本身，确保该目录直接包含 `manifest.json`。
5. 可将 Scope 固定到浏览器工具栏。

如果使用 ZIP 安装包，先解压，再选择解压后包含 manifest.json 的目录。浏览器的开发者模式只用于加载本地扩展，不需要关闭网站安全机制。

## 自动抽卡（新增）

**会真正通过网页控件提交生成任务，可能消耗账号额度。默认不启动，必须由你勾选费用确认后点击开始。** 我没有替你运行、测试或消耗额度。

1. 更新文件后，在浏览器扩展管理页点击该扩展的「重新加载」，并刷新目标网页，移除旧的页面脚本。
2. 打开你自己的 DesignArena 单 Agent 页面，确保没有任务正在生成。
3. 点击 Scope。依次为「新建会话」「输入框」「提交按钮」点击选择，然后在网页上点击对应控件。选择动作本身不会执行网页按钮；选择后重新打开插件继续。
4. 推荐绑定「完成标记」：应是任务完成才出现的唯一元素。新任务中需先消失再出现，才算完成。若不绑定，只在可识别的「停止生成」按钮出现后消失时判定完成；不能确认完成就停止。
5. 填写每轮任务、可选的目标型号、轮次与间隔，勾选费用确认，再点击「开始自动抽卡」。请先绑定完控件再填写任务，以免关闭弹窗时丢失未提交的草稿。
6. 插件逐轮新建会话、填入任务、提交并观察。目标型号仅与响应明确声明做不区分大小写的完整匹配，不根据回答内容猜测。

硬限制：每批最多 5 轮，默认 2 轮；轮间至少 30 秒，默认 60 秒；单轮等待默认 3 分钟，最大 10 分钟。默认没有唯一明确型号就停止；只有你勾选「型号未披露时也继续」，才继续到轮次上限。

检测到当前站点 fetch/XHR 的 HTTP 401 / 403 / 429、可见验证挑战、额度/鉴权错误提示时停止，不重试、不绕过。标签页转到后台或跳转到新文档也会停止。可随时点击插件或页面右上角的「停止抽卡」。**停止只影响后续提交，不会取消网站已经开始的任务或返还已消耗额度。**

控件绑定只保存在当前页面内存中。不猜测私有 API，不更换账号/令牌，不伪造可信事件；如果网站拒绝程序化点击、控件变化、需要新页面导航或无法确认完成，应停止后由你手动处理。HTTP 状态观察也不覆盖独立 EventSource、WebSocket、Web Worker 或页面已缓存的原始请求函数。

## 只读观察

1. 打开你自己的 DesignArena HTTPS 页面，并自行选择网站提供的单 Agent 会话。
2. 点击浏览器工具栏中的 Scope，再点右上角「只读观察」。
3. 点击「开始新一轮观察」。此时才在当前标签页安装探针。
4. 回到网页，正常提交你自己的任务。插件不提交任务，不消耗额外生成额度。
5. 再次点击插件查看型号声明、提供方、字段来源。可暂停 / 继续、停止探针、导出 JSON。

关闭插件弹窗不会停止页面内的监听。刷新或跳转到新文档后需重新点击开始；不同标签页分别启动，互不共用报告。

## 权限与隐私

仅申请：

- `activeTab`：用户点击插件时，临时访问当前标签页。
- `scripting`：按用户选择注入控件选择器、观察器或有上限的自动抽卡控制器；读取快照也使用此 API。

没有全站 host_permissions，没有常驻后台，没有 Cookie、storage、webRequest、debugger、downloads 或浏览历史权限。弹窗会检查当前地址，只允许 DesignArena 的 HTTPS 主机及其子域名。

页面内探针只观察当前站点正常收到的 fetch/XHR 数据；不额外访问网站端点、不读取请求体或认证头、不访问 Cookie 或浏览器存储。为提取字段，会短暂解析响应副本，但只保留并导出模型 / 提供方元数据。

自动抽卡是独立的可选模式，会将你填写的任务放入绑定输入框并点击可见控件，所以会产生网站正常生成请求与可能的费用。任务内容只用于本批操作，不写入浏览器持久存储；批次报告不导出任务内容、控件选择器、Cookie 或令牌。

弹窗打开时，每 1.5 秒通过浏览器脚本 API 读取页面内存里的快照；这不是网站网络轮询。关闭弹窗后停止读取快照。

## 结果边界

- 明确声明：本轮成功响应中出现一个明确型号；仅是原始声明。
- 歧义：多个型号 / 提供方声明，不选择或猜测。
- 仅内部 ID：不能当作型号名称。
- 未知：没有明确字段。

`summary.verified` 始终为 false。不会根据回答风格识别模型，不宣称能够看到服务端内部调用；也不会强制打开网站的单 Agent 功能或绕过认证、付费、防护与揭示机制。

每个响应限 512 KiB / 90 秒，并发副本限 4 个，最多保留 200 项。暂不覆盖 WebSocket、独立 EventSource、Web Worker 或跨站供应商请求。

## 文件

- `manifest.json`：MV3 与最小权限。
- `auto.html` / `auto.css` / `auto-popup.js`：默认的自动抽卡操作面板。
- `automation.js`：页面控件绑定、有限批次、结束检测与安全停止。
- `popup.html` / `popup.css` / `popup.js`：保留的只读观察面板。
- `probe.js`：完整内置单 Agent 探针，无外部代码加载。
- `README.md`：本说明。

未运行浏览器现场测试、自动验收或发布商店。是否能观察到型号，仍取决于网站实际返回的字段。
